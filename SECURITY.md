# Security policy

This integration controls real electrical equipment. Please report vulnerabilities **privately** through GitHub:
*Security › Report a vulnerability* (private vulnerability reporting) on this repository. Do not open public issues
for security problems.

- Supported: the latest release.
- Never paste API tokens (`wbx_…`), public URLs of your server or serial numbers in issues: the diagnostics download
  already redacts them.
- Expect a first answer within 7 days.
